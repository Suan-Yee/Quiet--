## Dark Mode Background Rules

Auth pages and normal app pages should not use the same background treatment.

Auth pages:
- Can use stronger generated SVG backgrounds.
- Background can be more decorative because the page has one centered form.
- Use auth-bg-light.svg and auth-bg-dark.svg.

Normal app pages:
- Should use calm warm dark background in dark mode.
- Do not use the auth background image globally.
- Decorative shapes must be very subtle.
- Feed/article/profile content must remain the focus.

Dark mode component rules:
- Cards must not stay white.
- Sidebar cards must use dark surfaces.
- Inputs must use dark input background.
- Borders must use warm dark border.
- Muted text must be readable.
- Avoid pure black and pure white.
